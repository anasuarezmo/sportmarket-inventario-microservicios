# Microservicios

Esta carpeta contiene la estructura inicial de los microservicios
definidos preliminarmente para el sistema de gestión de inventarios
de SportMarket S.A.S.

Los servicios identificados durante la primera entrega son:

- Catálogo
- Inventario
- Bodegas
- Compras y Proveedores
- Usuarios y Autenticación
- Devoluciones
- Reportes y Alertas

La implementación y definición detallada de cada microservicio se
realizará en las siguientes etapas del proyecto.
